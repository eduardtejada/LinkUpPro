1. ESTRUCTURA DE LA ARQUITECTURA ONION
--------------------------------------------------------------------------------
El proyecto está desacoplado en 5 capas concéntricas:
- Core/LinkUpPro.Core.Domain: Entidades y Enums del dominio (cero dependencias).
- Core/LinkUpPro.Core.Application: DTOs, ViewModels, Interfaces de repositorios y servicios.
- Infrastructure/LinkUpPro.Infrastructure.Persistence: ApplicationDbContext (EF Core Code First), Repositorio Genérico y Repositorios Específicos.
- Infrastructure/LinkUpPro.Infrastructure.Shared: Servicio de correos (MailKit) y Almacenamiento local de archivos/fotos.
- Presentation/LinkUpPro.Presentation.WebApp: Controladores MVC, Vistas Razor con Bootstrap 5, Middlewares y configuración de seguridad.

--------------------------------------------------------------------------------
2. BASE DE DATOS Y CONFIGURACIÓN
--------------------------------------------------------------------------------
La cadena de conexión por defecto utiliza SQL Server LocalDB y se encuentra en:
Presentation/LinkUpPro.Presentation.WebApp/appsettings.json:

"ConnectionStrings": {
  "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=LinkUpProDb;Trusted_Connection=True;MultipleActiveResultSets=true;TrustServerCertificate=True"
}

Para crear o actualizar la base de datos se puede realizar de 2 formas:

OPCIÓN A (Recomendada - Migraciones Code First de EF Core):
Desde la terminal en la raíz de la solución, ejecutar:
  dotnet ef database update --project Infrastructure/LinkUpPro.Infrastructure.Persistence --startup-project Presentation/LinkUpPro.Presentation.WebApp

OPCIÓN B (Script SQL incluido):
Se incluye el script SQL completo e idempotente en:
  Database/LinkUpProDb_Script.sql
Puede ejecutarse directamente en SQL Server Management Studio (SSMS) o Azure Data Studio.

--------------------------------------------------------------------------------
3. SERVICIO DE CORREO ELECTRÓNICO (SMTP)
--------------------------------------------------------------------------------
Configurado con MailKit en la capa Shared.
Las credenciales de correo se gestionan en appsettings.json.
- Modo Desarrollo amigable: Si el servidor SMTP no está disponible o las credenciales no están configuradas, el sistema NO bloquea la ejecución e imprime en grande el enlace de activación y restablecimiento directamente en la Consola / Ventana de Salida (Output) de Visual Studio.

--------------------------------------------------------------------------------
4. CÓMO EJECUTAR EL PROYECTO
--------------------------------------------------------------------------------
1. Abrir LinkUpPro.sln en Visual Studio 2022 / Rider / VS Code.
2. Asegurarse de tener instalado el SDK de .NET 9.
3. Establecer LinkUpPro.Presentation.WebApp como proyecto de inicio.
4. Presionar F5 (Iniciar Depuración) o ejecutar en terminal:
   dotnet run --project Presentation/LinkUpPro.Presentation.WebApp
